## Run locally

```bash
npm ci
npm test
npm start
```

The API starts on `http://localhost:3000`. Try `GET /health` or `GET /play`. There is no web homepage. `POST /play/1/answer` accepts `{"answer":"1/2"}`; `GET /scores/1` currently returns a placeholder score of zero.

The two HTTP tests cover `/health` and `/play`. They start and stop their own local servers, so a separate `npm start` process is not needed for testing.
